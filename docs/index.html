Hugging Face Adoption History (wss-hugging-face)

Point-in-time capture of Hugging Face Hub model adoption metrics (downloads, likes) for the text-generation ecosystem. The public API exposes only rolling windows and running totals; this archive preserves the history the source destroys, with an append-only manifest as the provenance record.

History held: 2026-08-31 to 2026-09-05.

Using it

Derived tables are CSV under data/ in the repository; the bytes they came from are under raw/, and SOURCES.md lists every source URL.

Every observation carries source_id and raw_ref. The matching manifest row holds that raw_ref with the URL, the fetch timestamp and a SHA-256 of exactly what came back, so any number here traces to the bytes it came from.

Cite this dataset by its repository and the date you took it from: https://github.com/neldivad/wss-hugging-face, accessed 2026-09-05.
